# نظام تقديم طلبات التوظيف (Job Application System)

مشروع بسيط تم تطويره باستخدام لغة **Java** وتقنية **JavaFX** كجزء من التكاليف الجامعية لمساق البرمجة.

## مميزات المشروع:
* **واجهة مستخدم رسومية (GUI):** مصممة باستخدام FXML لتسهيل إدخال البيانات.
* **نظام التنبيهات (Alerts):** تظهر رسائل تأكيد عند نجاح الحفظ أو تنبيهات عند نقص البيانات.
* **التحكم بحجم الخط:** استخدام Slider لتغيير حجم خط الملاحظات بشكل تفاعلي.
* **إدارة الملفات:** يقوم البرنامج بحفظ المراجعات والبيانات في ملف نصي خارجي باسم `employees_reviews.txt`.
* **رفع الصور:** إمكانية عرض صورة الموظف داخل الواجهة.

## الملفات الأساسية:
1. `JobApplicationSystem.java`: الملف الرئيسي لتشغيل التطبيق.
2. `JobApplicationController.java`: الملف المسؤول عن المنطق البرمجي والعمليات.
3. `JobApplication.fxml`: ملف تصميم الواجهة.

## طريقة التشغيل:
يتطلب تشغيل المشروع وجود **JDK 8** أو أحدث، ويمكن تشغيله مباشرة عبر بيئة **NetBeans**.
